[breaking] Store a quote that holds paragraphs as a container of lines (layout 5), and read and write layout 5 only: `MIN_LAYOUT`, `LAYOUT_VERSION` and `SEED_LAYOUT` are now 5

A shadow-root instance of a line class where blocks go (a quote made with `$createQuoteNode({shadowRoot: true})`) is now stored as a table cell is: a node of its own (`b:quote`, `c` = `'b'`) whose paragraphs are lines of its own sequence. Layout 4 stored it as a line whose paragraphs were nodes of their own, so Enter or Backspace in it moved text from one paragraph's node to another's: a collaborator typing in that text at the same time lost it (Backspace) or saw it land in the paragraph before the caret (Enter), and an edit addressed by block id across a concurrent Enter kept the old text beside the new. Now Enter inserts one marker and Backspace deletes one, as in the root. A quote that holds text directly is stored as before. A paragraph moved into a new quote while a collaborator types in it now leaves the typed text at its old position, as moving a paragraph into any other container does. A new room records only `lexical-y:5`. Rooms stored at layout 4 or lower open read only, showing their content, until they are migrated to layout 5 (`@lexical/y/migrate/4to5`, after the earlier steps). Older `@lexical/y` releases open a layout 5 room read only (`UNSUPPORTED_LAYOUT_WARNING`, reason `'newer'`). `loadYMigrationSteps` and the server's step lists now hold `YLayoutStep`s: a per-container step (`YLayoutMigration`, step contract 1) or a whole-root step (`YLayoutRootMigration`, step contract 2, which `4to5` is).

Migration: upgrade every client of a room together. A server migrates each stored room when it loads it, before serving it, with `prepareYRoom` (`@lexical/y/server`) or `migrateYState` (`@lexical/y/migrate`), whose default steps now include `@lexical/y/migrate/4to5` (a step list of your own adds it after `@lexical/y/migrate/3to4`); keep the generation fence (`checkYSession`) on every relay, and replace the incarnation of rooms not yet seeded (`needsNewIncarnation(room, SEED_LAYOUT)`), since the seed layout changed. A runner call that names its target passes `to: 5`. Code that reads a step from `loadYMigrationSteps` and calls `migrateContainer` or `rewrites` checks `step.v === 1` first.

Detect: rooms whose root records `lexical-y:4` (or lower) but not `lexical-y:5`; `UNSUPPORTED_LAYOUT_WARNING` with `reason: 'older'`; server step lists of your own without `@lexical/y/migrate/4to5`; code that reads `migrateContainer` or `rewrites` from the result of `loadYMigrationSteps` or from a `YLayoutStep`.

Verify: in a quote that holds paragraphs, press Enter in a paragraph while a collaborator types after the caret, and Backspace at the start of a paragraph while a collaborator types in it: their text stays where they typed it. Open a stored layout 4 room that holds such a quote after migrating it on the server: it is editable, reads as before and keeps every block id.
