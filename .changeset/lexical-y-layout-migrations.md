[feature] Layout migrations for stored documents (experimental): a floor below which the binding is read only, a runner with frozen steps, and the server helpers to migrate a room on load

What it adds: `MIN_LAYOUT`, the oldest layout the binding reads (1, so nothing changes for existing documents), with a read-only gate below it (`UNSUPPORTED_LAYOUT_WARNING` `{reason: 'older', found, min, supported, upgrade}` to `onWarn`, once per read-only period); `@lexical/y/migrate`, a runner that migrates a stored state with frozen steps (each naming its execution contract, `v: 1`) and reads a root's layout state (`getYLayoutInfo`: ready, missing, invalid or unsupported), loading only the published steps a document needs on demand (`loadYMigrationSteps(from, to?, {loaders?})`), one per layout (`@lexical/y/migrate/1to2`), checking the result on a copy before anything is written and recording the layout and an epoch (`lexical-y-epoch`, `YMigrationEpoch`: `{v: 1, kind, layout, client, clock, step, revision, schema?}`, unknown fields accepted; another version or a malformed epoch opens the document read only, like a malformed layout record); feature requirements (`lexical-y-require:<feature> = true`: a root that requires a feature this version does not support, or holds a malformed requirement, opens read only, kept and never rewritten, with `UNSUPPORTED_LAYOUT_WARNING` `'requires'`; the runner refuses to migrate such a root, `'unsupported-feature'`); `binding.quiesce()` (returning a `YQuiescedState`) and `onYMigrationEpoch` for handing a replica off and clearing undo; `SEED_LAYOUT`; and `@lexical/y/server`, the pieces a server uses to migrate a room on load and keep stale sessions apart (`prepareYRoom`, which runs every published step by default, `getYGeneration` (a versioned generation), `describeYRoom` and `checkYSession` (a versioned handshake with features and room requirements, seed contracts), `createYSessionCapture` and legacy signals, versioned quarantine records (`createYQuarantineRecord`, a canonical SHA-256 hash and a scoped acknowledgement, `sourceView`), and a Yjs-only `createYDoc` for a relay's documents)
