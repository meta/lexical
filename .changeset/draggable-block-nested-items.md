[feature] `DraggableBlockPlugin_EXPERIMENTAL` drags nested blocks on their own (list items, the blocks of a named slot) and takes a `$getBlockBehavior` prop to decide this per node

The handle targets the block under the pointer at any depth (a list item in a nested list, not the whole list), so `onElementChanged` now reports nested blocks too. Code that inserts next to the reported block should check where it is: inserting a paragraph after a list item splits its list or, for an item of a nested list, puts the paragraph inside the parent list item. Pass `$getBlockBehavior={() => 'atomic'}` to keep the handle on top-level blocks only.

A list item can be dropped into any list or outside a list (where it gets a new list of the same type), and a block that is not a list item dragged over a list lands next to that list, so the drop line only shows where the drop will happen. The drop line is indented to the target's left edge. On a nested target the upper half means "before" and the lower half "after"; a top-level target takes a drop before it only from above its top edge, as before. The pointer is now compared with the target in viewport coordinates, which also fixes drops in a scrolled window: a block dropped above the first block of a scrolled document used to land after it. A list whose last item is dragged out is removed.

The blocks of a multi-block named slot get a handle too; a single-line slot value does not. By default a shadow root (a table, a layout container) is still dragged as one block. The optional `$getBlockBehavior` prop decides per node whether a block is `'draggable'`, `'atomic'` (one unit, nothing inside gets a handle), `'transparent'` (no handle, but the blocks inside can get one) or `'ignored'` (no handle for it or anything inside). Blocks can be dropped into a shadow root whose blocks have handles, and a shadow root whose last block is dragged out keeps an empty paragraph.

Verify: in the playground, hover a list item (the handle appears for the item), drag it below another item of the same, a nested or another list, onto the upper half of the first item of a nested list, below a paragraph, and drag a paragraph onto a list item. Use "+" on a list item: the new block lands next to the list. Insert a collapsible: the handle over its title drags the whole collapsible, the paragraphs of its content have their own handles, and a paragraph can be dragged into and out of the content. Insert a pull quote: the paragraphs of the quote have their own handles, the attribution does not. Turn pages on: the blocks of a page have their own handles. Scroll a long document down and drop a block above its first visible top-level block and onto the upper half of the first item of a nested list: both land before the target.
